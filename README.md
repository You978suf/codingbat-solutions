# CodingBat Java Solutions

My solutions to [CodingBat](https://codingbat.com/java) Java practice problems, organized by category. CodingBat is a free site of short coding problems for building core Java skills.

| Folder | Topic | Solutions |

| `string1/` | Basic string manipulation | 33 |
| `string2/` | More advanced string problems | 9 |

**Total: 103 solved problems.**

## Running a solution

Each file contains a single static method. To test one locally:

```bash
javac Logic-1/caughtSpeeding.java
```

Then call the method from a small `main`, or paste it back into the CodingBat editor to verify.

A record of my Java practice, covering fundamentals: conditionals, loops, and string processing.
